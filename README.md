## Run locally

Install a JDK and clone the repository:

```bash
git clone https://github.com/saikishore2410/Java-ToDo-App.git
cd Java-ToDo-App
javac *.java
```

Run the class containing `main`; replace `Main` with the actual entry-point class if different.
